## 三、用户内容发布 + 审核流（新功能）

### 流程
用户（个人中心 → 内容发布）提交科普快讯 / 科普视频（B 站链接）→ 状态"待审核"→
管理员（后台 → 内容审核）通过 / 驳回（附原因）→ **仅已通过内容**合并进首页"科普快讯"与"热门科普视频"。

### 实现
- mock：`src/mock/submissions.ts`（localStorage 持久化），接口 `POST /api/submission`、`GET /api/submission/my`、`GET /api/admin/submission/list`、`POST /api/admin/submission/:id/review`（url 结构供 SpringBoot 对齐）；
- 用户端：个人中心新增"内容发布"Tab（发布表单 + 我的发布 + 审核状态/驳回原因）；
- 管理端：后台新增"内容审核"菜单与页面（状态筛选、通过/驳回、驳回原因必填、鼠标悬停查看审核意见）；
- 快讯与视频在提交时即校验必填项（快讯须正文、视频须 B 站链接）。

### 审核流实测（端到端）
user1 提交快讯 → 待审核 → admin 通过 → 首页科普快讯区出现该内容 ✅；驳回路径提示原因展示 ✅（种子数据演示）。

## 四、关于"真实图片"的说明

视觉中国照片受授权与防盗链限制，**必须由项目所有者登录 vcg.com 检索并下载授权副本**（水印预览图不可用，外链被 v-lazy 拦截）。全部 62 个图集位的文件名、目录、场景描述与 alt 文案已就绪（README 总表 + docs/15 检索清单），素材放入即自动点亮；在此之前展示原创占位图或"素材整理中"提示。
