## 素材处理要求

1. **格式**：webp（质量 75–80，单张 ≤ 200KB；可用 squoosh / sharp 等工具转换）。
2. **尺寸登记**：图片放入后，把真实像素宽高更新到 `src/mock/heritage-images.ts`
   的 `DEFAULT_WIDTH/DEFAULT_HEIGHT`（或按条目拆分）——这两个值渲染为 `<img>` 占位属性防 CLS。
3. **alt 描述**：每个文件位的场景描述已在清单中声明，自动拼接为
   "XX非遗项目，XX实拍图，图片用于毕业设计展示"，无需手写。
4. **禁止外链**：不得引用 vcg.com 等在线图片地址（防盗链 + 版权约束），
   `v-lazy` 指令会在运行时拦截并报错。
