## 2. 接口专项测试要点（补充说明）

1. **认证链路**：无 token 访问受保护接口 → 401；伪造/过期 token → 401"登录已过期"；user 角色访问 `/api/admin/**` → 403"无权限访问管理员接口"；
2. **统一返回结构**：全部接口返回 `{code, msg, data}`，分页接口 data 内含 `records/total/size/current/pages`；
3. **逻辑删除验证**：对分类/非遗/课程/评论/公告执行删除后，数据库 `deleted=1`、记录仍在，业务查询（含批量查询 `listByIds`）自动过滤；
4. **并发安全**：浏览量/收藏数使用数据库原子自增（`view_count = view_count + 1`），不存在"读-改-写"丢失更新；
5. **SQL 注入**：关键词搜索、筛选均经 MyBatis-Plus 预编译参数绑定，输入 `' OR '1'='1` 等注入串仅作为普通文本处理；
6. **越权防护**：资料修改使用专用 DTO（不可篡改 role/status）；删除评论校验归属；学习进度以章节记录校验课程归属。

## 3. 测试结论

系统 18 条核心功能用例全部通过，覆盖注册登录、内容浏览、收藏、评论、学习进度、文件上传、权限控制与后台管理八大业务域；认证（JWT）、逻辑删除、数据联动（收藏数/浏览量）、越权防护等关键机制均按设计工作。项目具备可演示、可答辩的完整度。
