## 二、逐页说明

### 1. 首页（含轮播）
- 结构：顶部导航（含站内搜索框）→ 轮播图 → 搜索区（热门标签）→ 今日非遗冷知识 → 接着看（登录态）→ 非遗分类 → 热门科普视频 → 科普快讯 → 猜你喜欢 → 最新公告 → 页脚。
- 轮播：自动切换 ≥5s、悬停暂停，图上左下角白底标题条（主色竖线 + #333 标题），指示器为短横线；每张图 `alt` 必填；`prefers-reduced-motion` 下动画停止。
- 响应式：≤768px 轮播高度 220px、隐藏箭头、分类 3 列、快讯单列。
- **版权声明**：页面底部固定渲染"素材来源：视觉中国，本作品仅用于毕业设计本地演示，非商用，不对外发布。"（12px/#999/居中）。

### 2. 非遗项目分类列表（兼站内搜索结果页）
- 结构：面包屑 → 搜索统计行（"找到 N 条与"关键词"相关的结果"，数字 Times New Roman）→ 筛选区（分类/级别/地区/关键词）→ 白色卡片栅格（4/3/2 列响应式）→ 统一分页 `AppPagination`。
- 筛选全部经 mock 分页接口（`/api/heritage/page`），筛选语义（模糊匹配、分页参数）与后端一致。
- 空结果展示 `el-empty` + 清空筛选引导。
- **版权声明**：卡片封面为视觉中国素材，页面底部渲染同一版权声明。

### 3. 非遗图文详情
- 结构：面包屑 → `<h1>` 标题 + 元信息行（地区/级别/发布时间）→ 基本信息卡（起源年代、代表作品、传承人链接、濒危程度、收藏/分享）→ 项目介绍（富文本 `.rich-content`）→ 项目图集（`PhotoGallery`）→ 相关科普视频 → 相关推荐 → 非遗小测验 → 评论区（分页）。
- 图集：懒加载（v-lazy）、width/height 占位防 CLS、键盘 ←/→ 切换、`aria-live` 播报进度；alt 模板"XX非遗项目，XX实拍图，图片用于毕业设计展示"。
- **版权声明**：图集组件内置版权备注 + 页面底部页面级版权声明，双保险。

### 4. 传承人列表
- 结构：面包屑 → 页头 → 横向条目卡（圆形肖像 + 姓名 + 头衔 + 简介 + 标签）。
- 悬停仅变边框色；肖像 `alt` 按模板生成；`width/height` 占位。
- **版权声明**：底部版权备注（肖像为视觉中国素材）。

### 5. 传承人详情
- 结构：面包屑 → 头部信息区（肖像 + 姓名 + 头衔 + 标签 + 简介）→ Tab（人物介绍/代表作品/关联非遗项目/相关科普视频）→ 底部版权备注。
- 关联项目、视频条目均可点击跳转对应详情页（mock 数据互通）。
- **版权声明**：底部版权备注。

### 6. 非遗地图（可选拓展，仅 mock）
- ECharts 中国地图按省份着色，**数据由 mock 点位（`src/mock/map-points.ts`，12 个点位含经纬度）推导**，未接真实接口。
- 统计卡（总数/覆盖省份/最多省份/未定位）+ 图例；点击省份跳转列表页地区筛选；地图容器带 `role="application"` + 文字替代说明。
- 页头明确标注"演示数据（mock 点位）"；预留给高德 JSAPI 的接缝为点位数据结构（GCJ-02 语义），升级路径见 docs/10 第 8 节。

### 7. 站内搜索与分页（贯穿模块）
- 搜索入口：顶栏搜索框（桌面端）+ 首页搜索区；回车/点击跳转 `/heritage?keyword=…`，列表页呈现结果统计与高亮筛选。
- 分页：全站统一 `AppPagination`（总数 + 上下页 + 页码 + 跳页，background 模式）。

## 四、对接真实 SpringBoot 的切换方式

1. `frontend/.env.development` 将 `VITE_USE_MOCK` 置为 `false`；
2. 确认 `VITE_API_BASE_URL` 指向后端地址；
3. 后端按 docs/08 接口文档提供同名接口（mock 路由表即接口契约清单：`src/mock/index.ts`）；
4. 图片素材上传后端 `/files/**` 后，把 mock 中的本地占位 URL 替换为接口返回的真实地址。
