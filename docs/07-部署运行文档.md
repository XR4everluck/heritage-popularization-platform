# 阶段7-1：系统部署运行文档

> 非遗知识教学平台（SpringBoot 2.7.18 + Vue3 + MySQL 8.0）从零到运行的完整步骤，以及常见问题排查。

---

## 1. 环境准备清单

| 软件 | 版本要求 | 说明 | 官网/获取方式 |
| --- | --- | --- | --- |
| JDK | 8 及以上 | 项目按 Java 8 编译目标构建；开发机若为 JDK 23+，pom 内置 profile 会自动开启注解处理（Lombok 正常工作） | Oracle / Adoptium |
| MySQL | 8.0.x | 字符集 utf8mb4；实测 8.0.34 | mysql.com |
| Node.js | ≥ 18（实测 22.16） | 前端构建与开发服务器 | nodejs.org |
| npm | ≥ 9（随 Node 附带） | 建议使用国内镜像 `https://registry.npmmirror.com` | - |
| Maven | 3.8+（可选） | 也可使用 IDEA 内置 Maven | maven.apache.org |
| 浏览器 | Chrome / Edge 现代版本 | 前台与后台均适配 | - |

> 推荐开发工具：IntelliJ IDEA（后端）、VS Code（前端）、Navicat/DataGrip（数据库）。

## 2. 后端启动步骤

### 2.1 创建数据库并导入脚本

方式一（命令行）：
```bash
mysql -uroot -p --default-character-set=utf8mb4 < sql\heritage_teaching_platform.sql
```
方式二（图形工具）：在 Navicat 中直接运行 `sql/heritage_teaching_platform.sql`。

脚本自动完成：创建数据库 `heritage_teaching`（utf8mb4）→ 创建 10 张表 → 写入演示数据（6 分类、4 非遗项目、2 课程、5 章节、轮播图、公告、2 个账号）。可重复执行（幂等）。

### 2.2 修改配置文件

编辑 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/heritage_teaching?...   # 按需改主机/端口/库名
    username: root              # TODO：改成你的数据库账号
    password: "你的数据库密码"    # TODO：改成你的数据库密码
heritage:
  jwt:
    secret: ${HERITAGE_JWT_SECRET:}   # 生产环境务必设置环境变量（≥32字节随机串）
```

> JWT 密钥说明：未设置 `HERITAGE_JWT_SECRET` 环境变量时，后端启动会自动生成随机密钥并告警——功能可用，但**重启后所有登录态失效**，仅限本机调试；答辩演示或部署时请设置固定密钥。

### 2.3 启动项目（三选一）

```bash
# 方式一：Maven 命令
cd backend
mvn spring-boot:run

# 方式二：IDEA 中直接运行 HeritageApplication 主类

# 方式三：打包后运行（生产/部署推荐）
mvn clean package -DskipTests
java -jar target/heritage-backend.jar
```

启动成功标志：控制台输出 `>>> 非遗知识教学平台后端启动成功`。
自检：浏览器访问 `http://localhost:8080/api/hello`，返回 `{"code":200,...}` 即正常；`/api/hello/db` 可验证数据库连通。

## 3. 前端启动步骤

```bash
cd frontend
npm install        # 首次安装依赖（国内建议先执行 npm config set registry https://registry.npmmirror.com）
npm run dev        # 启动开发服务器
```

访问 `http://localhost:5173`（后端地址在 `frontend/.env.development` 中配置，默认 http://localhost:8080）。

**测试账号**：管理员 `admin / 123456`，普通用户 `user1 / 123456`（后台管理入口 `http://localhost:5173/admin/login`）。

## 4. 生产部署（可选，答辩演示加分项）

推荐 Nginx 同源部署：前端静态文件与后端接口同域，彻底规避跨域。

```nginx
server {
    listen 80;
    # 前端：托管 Vue 构建产物（npm run build 生成 frontend/dist）
    location / {
        root D:/deploy/heritage/dist;
        try_files $uri $uri/ /index.html;   # Vue Router history 模式必需
    }
    # 后端接口反向代理
    location /api/ {
        proxy_pass http://localhost:8080;
    }
    # 上传文件静态访问
    location /files/ {
        proxy_pass http://localhost:8080/files/;
    }
}
```

部署步骤：`npm run build` → 拷贝 `dist/` 至服务器 → 后端 `java -jar heritage-backend.jar`（配置好数据库与 `HERITAGE_JWT_SECRET`）→ Nginx 按上述配置启动。

## 5. 常见问题排查（FAQ）

| 问题现象 | 可能原因与解决方案 |
| --- | --- |
| 后端启动报 `Access denied for user 'root'@'localhost'` | 数据库账号密码错误——检查 `application.yml` 的 username/password；MySQL 8 认证插件问题可执行 `ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '密码';` |
| 后端启动报 `Unknown database 'heritage_teaching'` | 未执行建表 SQL——先完成 2.1 步骤导入脚本 |
| 报 `Communications link failure` / 连接超时 | MySQL 服务未启动（服务面板启动 MySQL80）；或端口不是 3306——修改连接串 |
| 中文/emoji 存库报错或乱码 | 确认数据库与表字符集为 utf8mb4（建表脚本已内置）；命令行导入时加 `--default-character-set=utf8mb4` |
| 前端控制台 CORS / Network Error | 后端未启动或地址不对——检查 `.env.development` 的 `VITE_API_BASE_URL` 与后端 8080；后端 CorsConfig 已全局放行跨域，若自行收紧白名单注意同步 |
| 登录后刷新就掉线 / 重启后端后全员掉线 | 未设置 `HERITAGE_JWT_SECRET`，后端使用了随机密钥——设置环境变量后重启 |
| 报 `Port 8080 was already in use` | 端口占用——`netstat -ano | findstr :8080` 找到 PID，`taskkill /f /pid PID` 后重启；或改 `server.port` |
| 前端 `npm install` 缓慢/失败 | 切换国内镜像：`npm config set registry https://registry.npmmirror.com` 后重装 |
| 前端页面空白（生产部署） | Nginx 未配置 `try_files ... /index.html`（history 路由刷新 404） |
| 上传视频失败 | 检查类型（仅 mp4/webm/mov/avi/mkv）与大小（≤500MB）；Nginx 部署时需调大 `client_max_body_size` |
| JDK 23+ 编译报 Lombok 相关注解未生效 | pom 已内置 `jdk23plus-annotation-processing` profile 自动开启 `-proc:full`，勿删除；JDK 8~22 环境无此问题 |
| 管理员登录被拒"无权限访问管理员接口" | 该账号 role 不是 admin——使用 admin 账号，或在数据库中将目标用户 role 改为 admin |
