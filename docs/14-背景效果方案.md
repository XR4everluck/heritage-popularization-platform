# 14 - 背景图效果修改方案（已实现，待真实素材就位）

## 一、参考站观察结论（视觉呈现方式）

| 场景 | ihchina 的呈现方式 |
|---|---|
| 首页封面 | 全屏满铺非遗实物摄影图（织绣纹样）+ 居中白色大字标题 + 红色印章 + 底部专题指示点 |
| 内页（资讯等） | 浅色纸纹/织物纹理衬底铺满页面，内容白卡片浮于其上 |
| 内页页头 | 居中大字标题，两侧对称传统纹样装饰，标题下细分隔 |
| 细节 | 按钮带回纹角饰、日期旁菱形装饰符，装饰均为小面积点缀 |

对应到本项目的取舍（遵守 docs/11"克制庄重"规范）：
- **采纳**：纸纹衬底 + 白卡浮层、页头居中标题 + 对称纹样、小面积主色装饰；
- **不采纳**：全屏沉浸封面（与现有首页轮播功能重复）、深色满铺大图（与 #f8f8f8 浅色基调冲突）、任何背景动效/视差（规范禁止）。

## 二、已实现的三层方案

### 1. 全站衬底层（核心）
- 位置：`App.vue` 新增 `<div class="app-bg" aria-hidden="true">`，`position: fixed` 铺满、不随滚动、无动画；
- 效果：`#f8f8f8` 底色之上叠加**透明度 8%** 的非遗背景图（移动端降至 5%），白卡浮于其上——即 ihchina 内页"纸纹衬底"的克制版；
- 可读性保障：8% 透明度经核算不破坏正文对比度（#666 on 衬底仍 ≥ 4.5:1，满足 docs/11 无障碍要求）；
- 素材解析：`src/composables/useAppBackground.ts` 用 `import.meta.glob` 收集本地素材，**优先级 `bg.webp > bg.jpg > bg.png > 其他`**，写入 CSS 变量 `--app-bg-image`；**素材未就位时自动退回纯色底**（构建不依赖素材存在）。

### 2. 页头横幅范式（已应用到三个页面）
- 新增全局样式 `.gq-page-header`：居中大标题 + **两侧对称主色菱形纹样** + 副题 + 通栏细横线；
- 应用：非遗博览列表页（新增横幅"非遗博览"）、传承人专题列表页、非遗地图页；
- 搜索结果态自动隐藏横幅、显示"找到 N 条相关结果"统计行。

### 3. 内置演示纹理（即时可见）
- `src/assets/intangible-images/bg/demo-pattern.svg`：**原创**几何"回纹角饰 + 菱形格 + 洒金点"纹样（无第三方版权），已随代码入库；
- 当前全站即以此演示真实效果；真实素材放入后自动退位。

## 三、视觉中国素材挑选清单（vcg.com）

### 地图页背景（bg/map-bg.webp 专用，本轮已实际检索选图）

检索入口：vcg.com 搜索"**雕版印刷 手工**"（11,145 个素材）。选图标准：横构图、深棕暗调、纹理满幅、亮度低（垫金色地图不抢焦点）。

| 优先级 | 候选（按标题在 vcg 精确检索） | 推荐理由 |
|---|---|---|
| 首选 | **非遗传承连城四堡雕版印刷** | 暗色满幅雕版特写，与 ihchina #page5 的暗色雕版背景同类型同气质，非遗属性契合 |
| 备选 1 | **雕版印刷** | 印经板特写，暗棕木纹质感 |
| 备选 2 | **木板雕刻** / 老人手拿刻刀雕刻 | 手部工艺动作，叙事感强 |

放入方式：取得授权副本 → 转 webp → 命名 `map-bg.webp` 放入 `src/assets/intangible-images/bg/` → 刷新自动替换内置演示纹理（`map-bg.svg`，原创无版权）。

检索入口（已实测可用）：
- 搜索"**中国传统纹样 底纹 背景**"（37,175 个素材）——衬底类首选来源；
- 搜索"**非遗 剪纸 背景**"（3,559 个素材）——封面/横幅类照片。

衬底用途候选（按与项目契合度排序）：
| 候选 | 类型 | 契合理由 |
|---|---|---|
| 洒金纸背景 | EPS 底纹 | 米白宣纸洒金质感，与 #f8f8f8 底色最契合，**首选** |
| 无缝的云纹线条背景连续图案 | EPS 可平铺 | 云纹典雅，适合平铺衬底 |
| 中国传统图纹边框 白色背景素材 | EPS | 浅底 + 纹样边框，适合页头横幅区 |
| 中式祥云边框底纹背景 | EPS | 祥云意象，契合非遗主题 |

封面/轮播帧候选（暗红系，配合主色 #9E2021）：
- 中国传统文化云纹纹样印花图案
- 中式传统装饰花纹纹样红色喜庆背景

**接入步骤（三步，零代码）**：
1. 登录 vcg.com 按上述标题/关键词检索，取得授权副本（本项目为毕设本地演示用途，请按视觉中国授权条款选购）；
