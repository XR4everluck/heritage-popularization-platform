## 三、真前后端联调（真实 SpringBoot）——差一步

本机环境已具备：Java 26 ✅、MySQL 8.0.34（服务运行中）✅、后端 jar 已构建（target/heritage-backend.jar）✅、建库脚本齐全（sql/）✅。
**唯一阻塞**：`backend/src/main/resources/application.yml` 的数据库密码为占位符"请修改为你的数据库密码"，本机 root 非空密码/非 root（已实测）。

**启用真联调步骤**：
1. 把你的 MySQL root 密码填入 `application.yml` 的 `spring.datasource.password`；
2. 首次执行 `sql/heritage_teaching_platform.sql`（及增量脚本）建库；
3. `VITE_USE_MOCK=false`，启动后端 jar（`java -jar target/heritage-backend.jar`）与前端 `npm run dev`；
4. 按本表用例回归即可（接口 URL 与 mock 完全一致，无需改前端）。
