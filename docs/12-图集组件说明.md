# 12 - 图集/详情图片组件说明（供毕设文档引用）

> 对应模块：图文详情、传承人详情的图片展示区
> 规范依据：docs/11 全局设计规范 第 1.1、1.2、2、4.1、6.2、6.4 节
> 构建验证：`npm run build` 通过（2026-10-11）

---

## 1. 组件清单

| 文件 | 职责 |
|---|---|
| `src/components/PhotoGallery.vue` | 图集组件：主图区 + 缩略图条 + 大图查看 + 版权备注 |
| `src/directives/lazy.ts` | `v-lazy` 自定义懒加载指令（零依赖，IntersectionObserver 实现） |
| `src/utils/alt-text.ts` | alt 描述模板生成与合规校验 |
| `src/types/models.ts` | `GalleryImage` 类型定义 |
| `src/mock/heritage-images.ts` | 图集 mock 数据清单（按分类目录 + 文件名定位素材） |
| `src/assets/intangible-images/` | 本地素材目录，按非遗分类建子目录（craft/fine-arts/music/dance/opera/folk） |

## 2. 使用方式

```vue
<script setup lang="ts">
import PhotoGallery from '@/components/PhotoGallery.vue'
import { exampleGalleryImages } from '@/mock/heritage-images'
</script>

<template>
  <PhotoGallery :images="exampleGalleryImages" @change="onImageChange" />
</template>
```

组件 Props：

| Prop | 类型 | 说明 |
|---|---|---|
| `images` | `GalleryImage[]` | 必填。`{ src, alt, width, height, caption? }`，src 仅允许本地资源 |
| `initial` | `number` | 初始下标，默认 0 |
| `copyrightNote` | `string` | 底部版权备注，默认合规文案，一般不传 |

事件：`change(index)` —— 当前图切换时触发。

## 3. 专项要求的实现方式

### 3.1 图片加载
- **本地静态资源**：素材统一放 `src/assets/intangible-images/<分类>/`，通过
  `import.meta.glob` 收集构建产物内 URL；mock 条目按"分类子目录 + 文件名"声明。
- **禁止外链（代码级约束）**：`v-lazy` 指令对 `http://`、`https://` 开头的地址一律拦截，
  控制台报错并显示占位图——视觉中国 vcg.com 等防盗链站点即使误配也无法加载。
- **webp 格式**：素材处理要求写入素材目录 README（质量 75–80，单张 ≤ 200KB）。
- **懒加载**：自定义 `v-lazy` 指令，IntersectionObserver 提前 200px 预加载，
  不支持的浏览器降级为立即加载；未引入第三方懒加载库。
- **CLS 防布局偏移**：每张图强制渲染 `width`/`height` 属性（值来自 mock 数据登记的
  真实像素尺寸），浏览器在图片下载前即可计算宽高比，页面不跳动。
- **多屏适配**：主图 `max-height` 桌面 520px / 移动 280px，缩略图 72px / 56px，
  缩略图条横向滚动；≤768px 断点切换。

### 3.2 无障碍
- 所有 `<img>` 必带 alt，由 `buildAlt(项目名, 场景)` 统一拼接为
  "XX非遗项目，XX实拍图，图片用于毕业设计展示"；`warnInvalidAlt` 在开发期对
  "图片"等泛称告警。
- 主图可聚焦（`tabindex="0"`），键盘 ←/→ 切换上一张/下一张；
- 切换按钮带 `aria-label="上一张图片/下一张图片"`；缩略图为装饰性重复图（`alt=""`），
  语义由按钮的 `aria-label` 承载，当前项带 `aria-current`；
- 隐藏的 `aria-live="polite"` 区域向读屏播报"第 X 张，共 Y 张"；
- 大图查看器支持 Esc 关闭（Element Plus 内建）。

### 3.3 版权合规
- 组件底部固定渲染版权备注（12px、#999、居中、与图片区块间距 16px）：
  "素材来源：视觉中国，本作品仅用于毕业设计本地演示，非商用，不对外发布。"
- `src/assets/intangible-images/.gitignore` 将 `*.webp` 排除出版本库；
  项目建议设为私有仓库，答辩结束后删除该类图片（详见素材目录 README.md）。

## 4. 降级与边界行为

| 情形 | 表现 |
|---|---|
| 素材文件尚未放入 | src 为空串，主图区显示"该项目的图片素材整理中"，不报错 |
| 图片 404（文件名与 mock 不符） | 占位图 + `is-lazy-error` 灰底，控制台可见网络错误 |
| mock 传入外链地址 | v-lazy 拦截，控制台报错，显示占位图 |
| alt 为泛称（如"图片"） | 开发模式控制台告警，提示修正 |
| 图集仅 1 张图 | 隐藏切换按钮与缩略图条，保留计数与版权备注 |

## 5. 与后端联调的衔接（下一步）

真实接口就绪后，仅需在 `api/front.ts` 增加图集查询函数并返回
`{ src, alt, width, height, caption }[]`（替换 mock 清单），组件零改动。
`width`/`height` 建议由后端文件元数据或发布流程落库，保证 CLS 防偏移持续有效。

## 6. 遗留事项（不影响本组件验收）

- 构建产物中 `index` 与 `HeritageMap` 两个 chunk 超过 500KB：前者源于 Element Plus
  图标全量注册（docs/10 已列入按需加载优化项），后者源于内置 GeoJSON，均与本组件无关。
