# 阶段6：Vue3 前端项目（前台 + 后台）说明

> 阶段6目标：Vue3 + Vite + Element Plus + Axios 生成完整前端，对接 SpringBoot 后端（默认 http://localhost:8080），含用户前台展示端与管理后台端。

---

## 1. 项目结构与启动

```
frontend
├── package.json / vite.config.js / index.html / .env.development
└── src
    ├── main.js / App.vue / styles/global.css
    ├── api            # 接口封装（按模块）
    │   ├── user.js    # 登录/注册/个人资料
    │   ├── front.js   # 前台展示+用户操作（分类/非遗/课程/轮播图/公告/收藏/评论/进度）
    │   ├── admin.js   # 后台管理（分类/非遗/课程章节/用户/评论/轮播图/公告）
    │   └── file.js    # 文件上传
    ├── utils
    │   ├── request.js # axios 封装：统一 baseURL、自动携带 token、401 跳登录、错误统一提示
    │   └── placeholder.js  # 本地 SVG 渐变占位封面（无外网依赖，防止种子数据破图）
    ├── store/user.js  # Pinia 登录态（token+用户信息，localStorage 持久化）
    ├── router/index.js# 路由（前台/后台）+ 登录守卫 + admin 角色守卫 + 页面标题
    ├── layout
    │   ├── FrontLayout.vue  # 前台：顶部导航 + 用户区 + 页脚
    │   └── AdminLayout.vue  # 后台：深色侧边菜单 + 顶栏 + 主内容区
    ├── components/FileUpload.vue  # 通用上传组件（v-model 绑定 URL，图片/视频）
    └── views
        ├── front  # 登录、首页、非遗列表、非遗详情、课程学习、个人中心（6页）
        └── admin  # 登录、数据统计、分类/非遗/课程/用户/评论/轮播图/公告管理（10页）
```

**启动方式**：
```bash
cd frontend
npm install
npm run dev        # 开发：http://localhost:5173（后端需在 8080 运行）
npm run build      # 生产构建
```

**测试账号**：admin / 123456（管理员），user1 / 123456（普通用户）。

## 3. 前端技术要点

1. **axios 封装**（`utils/request.js`）：baseURL 取 `.env.development` 的 `VITE_API_BASE_URL`；请求拦截器自动携带 `Authorization: Bearer {token}`；响应拦截器统一处理——`code!==200` 弹错，`401` 清除登录态并按前台/后台分别跳转登录页；
2. **路由守卫**（`router/index.js`）：`/profile` 需登录；`/admin/**` 需登录且 `role==='admin'`（前端守卫 + 后端拦截器双重校验）；动态页面标题；
3. **登录态**：Pinia store + localStorage 持久化，刷新不丢失；
4. **富文本**：wangeditor 5（@wangeditor/editor-for-vue）编辑非遗详细介绍，前台 `v-html` 渲染；
5. **上传**：通用 `FileUpload` 组件封装 `POST /api/file/upload`，图片/视频两型，el-upload 自定义 http-request，v-model 双向绑定文件 URL；
6. **占位封面**：`utils/placeholder.js` 生成渐变 SVG data-URI，种子数据无图片文件时页面不破图（上传真实图片后自然替换），无任何外网图片依赖；
7. **统计数字**：Dashboard 复用 4 个分页接口（pageSize=1）读取 total，后端无需新增统计接口。

## 4. 过程中修复的问题（E2E 实测发现）

1. **CORS 预检被拦截**：携带 `Authorization` 头的跨域请求会先发 OPTIONS 预检，JwtInterceptor 将其拦截导致后台接口全部 Network Error——已在拦截器中放行 OPTIONS 请求（`backend/.../interceptor/JwtInterceptor.java`）；
2. **种子图片破图**：banner 路径无对应文件、via.placeholder.com 外网不可达——新增本地 SVG 占位封面并全局替换（`frontend/src/utils/placeholder.js`）；
3. **"我的评论"接口缺失**：个人中心需要，后端补充 `GET /api/comment/my`（UserCommentService.pageMy，需登录）。
