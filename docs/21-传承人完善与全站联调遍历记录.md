## 四、本轮发现并修复的问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | **后端 JWT 使用随机密钥**：每次重启后端所有登录态失效，用户被强制登出（首页受保护接口 401 → 数据未加载） | `application.yml` 配置固定密钥（本地默认值 + 生产环境变量覆盖说明），重启后登录态保持 |
| 2 | 传承人"代表作品"后端为硬编码空数组（无数据结构） | 表加 `works` JSON 字段 + 数据填充 + 详情接口解析 |
| 3 | 传承人列表缺关联项目信息 | 列表 VO 补 `heritageName`，前端加标签 |
| 4 | 全民科普内容空泛 | SQL 填充 5 条已通过内容（真实后端持久化） |
| 5 | 脚本执行排序规则冲突（gbk 连接 vs utf8mb4 列） | MySQL 客户端连接指定 `--default-character-set=utf8mb4` |
