# 阶段7-2：接口文档（毕设答辩 / 联调用）

> 基础地址：`http://localhost:8080`。除标注"公开"外的接口均需在请求头携带：
> `Authorization: Bearer {token}`（登录接口获取）。
> **统一返回结构**：`{ "code": 200, "msg": "操作成功", "data": ... }`；`code=200` 成功，400 参数错误，401 未登录/令牌失效，403 无权限，500 系统异常（业务提示见 msg）。
> 分页返回结构：`data: { records: [...], total, size, current, pages }`。
> 时间字段统一输出 `yyyy-MM-dd HH:mm:ss`；所有列表/详情查询自动过滤已逻辑删除数据。

图例：🔓 公开接口 | 🔐 需登录 | 👑 需管理员

## 1. 用户模块 `/api/user`

| 方法 | 路径 | 权限 | 参数 | 说明 |
| --- | --- | --- | --- | --- |
| POST | `/api/user/register` | 🔓 | body：`{username, password, nickname?}` | 注册；用户名 3-50 位字母数字下划线，密码 ≥6 位；用户名重复报"已被注册" |
| POST | `/api/user/login` | 🔓 | body：`{username, password}` | 登录成功返回 token 与用户信息 |
| GET | `/api/user/profile` | 🔐 | - | 查询个人信息（身份来自 token） |
| PUT | `/api/user/profile` | 🔐 | body：`{nickname?, phone?, email?, avatar?, introduction?}` | 修改资料（仅更新传入字段） |

**登录返回示例**：
```json
{
  "code": 200, "msg": "操作成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": { "id": 2, "username": "user1", "nickname": "非遗爱好者", "role": "user",
              "status": 1, "createTime": "2026-10-04 17:09:06", "password": null }
  }
}
```

## 12. 错误码约定

| code | 含义 | 典型场景 |
| --- | --- | --- |
| 200 | 成功 | - |
| 400 | 请求参数错误 | 校验失败、非法文件类型 |
| 401 | 未登录/令牌失效 | 未携带 token、token 过期、账号被禁用 |
| 403 | 无权限 | 普通用户访问管理员接口、删除他人评论 |
| 404 | 资源不存在 | 详情已删除/未发布 |
| 500 | 系统异常 | 兜底（业务异常会返回具体提示，如"用户名或密码错误"、"已收藏过该项目"） |
