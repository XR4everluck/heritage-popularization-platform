# 阶段2：SpringBoot 后端项目骨架说明

> 阶段2目标：生成标准后端项目结构、依赖配置、基础通用配置类。
> 本文档同时给出包结构说明、依赖清单、各配置类的作用与验证记录。

---

## 1. 项目结构

```
backend
├── pom.xml                                            # Maven 依赖管理
└── src
    ├── main
    │   ├── java/com/heritage
    │   │   ├── HeritageApplication.java               # 启动类（@MapperScan 扫描 mapper 包）
    │   │   ├── common                                 # 通用返回封装
    │   │   │   ├── Result.java                        # 统一返回结果（code/msg/data）
    │   │   │   └── ResultCode.java                    # 全局状态码枚举
    │   │   ├── config                                 # 全局配置
    │   │   │   ├── CorsConfig.java                    # 全局跨域配置
    │   │   │   └── MybatisPlusConfig.java             # 分页插件（逻辑删除在 yml 全局配置）
    │   │   ├── controller                             # 控制层（接口入口）
    │   │   │   └── HelloController.java               # 自检接口（开发用，业务开发后可删）
    │   │   ├── service                                # 业务接口层
    │   │   │   └── impl                               # 业务实现层
    │   │   ├── mapper                                 # MyBatis-Plus Mapper 接口
    │   │   ├── entity                                 # 数据库实体类（对应10张表）
    │   │   ├── dto                                    # 请求参数对象（前端入参）
    │   │   ├── vo                                     # 视图对象（返回给前端的视图数据）
    │   │   ├── util                                   # 工具类（阶段3：JWT、密码加密等）
    │   │   └── exception                              # 异常
    │   │       ├── BusinessException.java             # 业务异常（Service 层手动抛出）
    │   │       └── GlobalExceptionHandler.java        # 全局异常处理器
    │   └── resources
    │       ├── application.yml                        # 全局配置文件
    │       └── mapper                                 # MyBatis XML（复杂 SQL 时使用）
    └── test
        └── java/com/heritage
            └── HeritageApplicationTests.java          # 上下文加载测试
```

分层调用关系：`controller → service → mapper`；跨层数据传输用 `dto`（入参）/`vo`（出参），`entity` 只与数据库表对应。

## 3. 核心配置说明

### 3.1 统一返回结果 Result（common/Result.java）

所有接口统一返回 `{ code, msg, data }`：

- `code = 200` 表示成功，其余为失败，取值见 `ResultCode` 枚举（200/400/401/403/404/500，业务模块后续可扩展 1xxx 段）；
- 用法：`Result.ok()`、`Result.ok(data)`、`Result.error("提示")`、`Result.error(ResultCode.UNAUTHORIZED)`。

### 3.2 全局异常处理器（exception/GlobalExceptionHandler.java）

| 异常类型 | 处理方式 |
| --- | --- |
| `BusinessException` | 返回业务提示（Service 层校验失败时手动抛出） |
| `MethodArgumentNotValidException` / `BindException` / `ConstraintViolationException` | 拼接字段级错误信息，返回 400 |
| `MaxUploadSizeExceededException` | 返回"上传文件过大" |
| `Exception`（兜底） | 记录完整 error 日志，对外只返回"系统繁忙"，不暴露内部信息 |

### 3.3 跨域配置（config/CorsConfig.java）

允许所有来源跨域访问（`allowedOriginPatterns("*")` + 允许携带凭证）；Spring 5.3+ 中 `allowCredentials(true)` 不能搭配 `allowedOrigins("*")`，故使用 `allowedOriginPatterns`。生产部署时建议收紧为前端实际域名。

### 3.4 MyBatis-Plus 配置

- **分页插件**（config/MybatisPlusConfig.java）：注册 `PaginationInnerInterceptor`（MySQL 方言），单页上限 100 条；业务层直接传 `Page<T>` 即物理分页；
- **逻辑删除**（application.yml 全局配置）：`logic-delete-field: deleted`，实体含 `deleted` 字段即自动生效——查询自动拼接 `deleted=0`，`removeById` 自动改写为 `UPDATE ... SET deleted=1`；
- **驼峰映射**：`map-underscore-to-camel-case: true`，与建表 SQL 的下划线字段对应；
- **主键策略**：`id-type: auto`，与建表 SQL 的自增主键一致。

### 3.5 application.yml 关键项

- 端口 `8080`；数据库连接串含 `serverTimezone=Asia/Shanghai`、`characterEncoding=UTF-8`（驱动层自动映射 utf8mb4）；
- **数据库账号密码为预留占位**（`TODO` 注释处），运行前必须改成你本机 MySQL 的真实账号密码；
- Jackson 统一输出 `yyyy-MM-dd HH:mm:ss` 时间格式；
- 文件上传单文件上限 100MB（阶段3调整）；
- 开发期开启 SQL 打印（`log-impl: StdOutImpl`），上线前删除。

## 4. 运行方式

```bash
cd backend
mvn spring-boot:run            # 或在 IDEA 中直接运行 HeritageApplication
```

启动成功后自检：

- 浏览器访问 `http://localhost:8080/api/hello` → 返回 `{"code":200,"msg":"操作成功","data":"...运行中"}`；
- 访问 `http://localhost:8080/api/hello/db` → 验证数据库连通（返回数据库服务器时间）。

## 5. 本机环境适配说明（JDK 26 特有，JDK 8 环境无需关注）

- 本机默认 JDK 为 26，而 JDK 23 起 javac 默认禁用注解处理器（JDK 8~22 无此行为）。pom 中已加入 `jdk23plus-annotation-processing` profile：**仅在 JDK 23+ 环境自动激活**并开启 `-proc:full`，保证 Lombok 生效；JDK 8 环境不受任何影响；
- Lombok 版本固定为 1.18.48：兼容 JDK 8 编译，同时兼容新版 JDK；
- 旧坐标 `mysql:mysql-connector-java` 已被 Maven 重定向到 `com.mysql:mysql-connector-j`，两者驱动类相同（`com.mysql.cj.jdbc.Driver`）。
